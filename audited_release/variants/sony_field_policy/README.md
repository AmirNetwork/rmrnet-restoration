# Sony ILX-LR1 field-policy code

This directory contains the later detector wrapper, field-policy audits, and the audited result ledgers used for the Sony ILX-LR1 field study. The field images and third-party YOLO26s checkpoint are not redistributed here. The manuscript records the detector source, license, inference settings, and checkpoint SHA-256.

The 46 project-collected frames remain at 4752 x 3168 for restoration and annotation. Forty-four common-taxonomy frames are scored. No synthetic degradation is added. Direct single-view results and the chronological 22/22 calibration/evaluation policy are separate analyses.
