# Third-Party Components

TRACE-R source files include integration adapters and evaluation scripts for third-party projects. Those projects retain their own authorship, licenses, and citation requirements.

- Ultralytics YOLO11/YOLO8/YOLO26: AGPL-3.0 or an applicable Ultralytics Enterprise license. See `https://docs.ultralytics.com/`.
- YOLO26s RDD-FRDC Distilled v2 checkpoint: model card declares AGPL-3.0. See `https://huggingface.co/TamAko783/YOLO26s_RDD_FRDC_Distilled_v2`.
- DFPIR: use the license and terms in the official repository, `https://github.com/TxpHome/DFPIR`.
- DeMoE: use the license and terms in the official repository,
  `https://github.com/cidautai/DeMoE`.
- NAFNet: use the license and terms in the official Megvii repository,
  `https://github.com/megvii-research/NAFNet`.
- KITTI raw data: use is governed by the KITTI dataset terms.

The release ZIP does not relicense third-party checkpoints or datasets. Users must obtain those artifacts from their original sources and comply with their terms.
