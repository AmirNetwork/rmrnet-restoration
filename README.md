# TRACE-R journal release

This branch contains the audited journal release of **TRACE-R: Telemetry-Routed
Adaptive Corruption-Expert Restoration for Pavement Inspection**.

The clean, tested release is in [`TRACE_R_journal_release/`](TRACE_R_journal_release/README.md).
It contains the method code, matched-training and evaluation scripts, tests,
environment specifications, and the frozen validation-only provenance ledger.

Author: Amir Ghorbani (`amir.ghorbani@rmit.edu.au`)

Earlier root-level files and `RMRP_v50_code/` are retained as historical
artifacts for the RMR-P conference precursor. They are not the TRACE-R journal
implementation.
