# TRACE-R journal release

This branch contains the audited journal release of **TRACE-R:
Telemetry-Conditioned Restoration for Road-Defect Detection**.

The clean, tested release is in [`TRACE_R_journal_release/`](TRACE_R_journal_release/README.md).
It contains the single-output method code, matched training and evaluation
scripts, tests, environment specifications, paper source, and frozen result
provenance. The released method does not fuse restoration outputs or detector
predictions.

Author: Amir Ghorbani (`amir.ghorbani@rmit.edu.au`)

Earlier root-level files and `RMRP_v50_code/` are historical artifacts for the
arXiv precursor. They are not the implementation evaluated in the TRACE-R
journal manuscript.
